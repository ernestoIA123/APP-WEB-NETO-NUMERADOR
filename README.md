# NETO NUMERADOR

Aplicación web para enumerar hasta 1000 imágenes y videos y descargar los archivos renombrados dentro de un ZIP.

## Funciones

- Selección de archivos o carpetas completas.
- Arrastrar y soltar imágenes, videos o carpetas.
- Vista previa, nombre actual, formato, peso y nombre nuevo.
- Numeración automática con prefijo personalizado.
- Conversión de todas las imágenes a PNG conservando sus dimensiones originales.
- Los videos conservan su formato y resolución originales.
- El botón Borrar todo limpia los archivos y reinicia la barra de procesamiento a 0%.
- Procesamiento completamente local en el navegador.
- ZIP sin dependencias externas.
- Diseño adaptable a celular, tablet y computadora.

## Uso local

Abre `index.html` con Live Server en Visual Studio Code.

## Publicación

El proyecto es estático y puede publicarse directamente en Vercel. No necesita comando de compilación ni variables de entorno.
